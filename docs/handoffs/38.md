### 4.3 ⚠️ 第 7 次的遗留缺陷：发单后 loop RuntimeError（已修）

发单 ACCEPTED 之后，node 抛：
```
[ERROR] TradingNode: Error on run
RuntimeError(Event loop stopped before Future completed.)
  File ".../live/node.py", line 298, in run
    self.kernel.loop.run_until_complete(self.run_async())
```
- **订单安全**：203920 已被交易所 accept，挂在 testnet；Python 进程崩溃**不撤交易所挂单**。
- **根因（D1–D3 raw 坐实）**：注入块用 sync `_inj_provider.load_ids([_iid])`，其内部 `get_event_loop()` 在 `node.build()` 后 `run()` 前返回的就是 **kernel.loop**（当前 loop），`run_until_complete` 把它 run-then-stop 了一次；随后 `node.run()`（node.py L298）再 `self.kernel.loop.run_until_complete(...)` 同一只被停过的 loop → 报 `Event loop stopped`。

### 4.4 loop 修复经过（v1 错→v2 对，本会话教训）

- **v1（错）**：`finally: asyncio.set_event_loop(node.kernel.loop)` —— production 行，但单测里 `node` 是 MagicMock → `node.kernel.loop` 也是 MagicMock → `asyncio.set_event_loop` 拒收 → 注入块崩 → 6 个 `TestTradeLiveLiveWiring` 测试挂（`6 failed, 686 passed`）。CC 未自行乱修，回贴 raw。
- **v2（对，当前文件状态）**：不引用 `node.kernel.loop`，改为「换之前捕获当前 loop、finally 还原它」。`_prev_loop` 是真 asyncio loop/None，永不是 mock → **692 全恢复（含 6 wiring）**。已签静态 CLEAN。

### 4.5 cli.py 当前注入块（loop 修正版，逐字现状，约 L200–L224）

```python
node.build()
# ---- 路径 C：注入现货 instrument 进 cache（== RiskEngine 读的 Cache）----
_inj_clock = LiveClock()
_inj_http = BinanceHttpClient(            # exchangeInfo 公开端点，无需凭据
    clock=_inj_clock, api_key=None, api_secret=None,
    base_url=_TESTNET_BASE,
)
_inj_provider = BinanceSpotInstrumentProvider(
    client=_inj_http, clock=_inj_clock, account_type=BinanceAccountType.SPOT,
)
_iid = InstrumentId(Symbol(symbol.upper()), Venue("BINANCE"))
# 隔离 loop：临时 loop 跑加载，绝不触碰 kernel.loop（否则 run() 报 Event loop stopped）
try:
    _prev_loop = asyncio.get_event_loop()
except RuntimeError:
    _prev_loop = None
_load_loop = asyncio.new_event_loop()
asyncio.set_event_loop(_load_loop)
try:
    _inj_provider.load_ids([_iid])        # get_event_loop()→_load_loop，跑临时 loop
finally:
    asyncio.set_event_loop(_prev_loop)    # 还原「换之前的当前 loop」，不引用 node.kernel.loop
    _load_loop.close()
_instrument = _inj_provider.find(_iid)
assert _instrument is not None, f"path-C: provider 未取到 {_iid}"
node.kernel.cache.add_instrument(_instrument)
assert node.kernel.cache.instrument(_iid) is not None, f"path-C: cache 回读 {_iid} 空"
# ---- 路径 C 结束 ----
node.trader.add_strategy(strategy)
node.run()
```
