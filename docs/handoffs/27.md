## §3 本会话设计教训

### reconcile 失效 → direct cache injection

- **事发**: 原 option (b) `exec_engine.process(synth_fill)` 未能将 NT portfolio net_position 顶到 0.07（synth_order 状态机未走到 ACCEPTED，`OrderFilled` 被拒处理）
- **修法**: 改为直接向 NT cache 注入合成 Position（`PortfolioFacade.cache.add_position()`），`net_position` 读到 0.07
- **影响**: CB11 tie-back 降为构造性永真（见三段诚实标注）；真实验证力移至 post_net==0
- **教训**: NT 状态机对 synth events 有严格状态前置要求；direct cache injection 是有效 workaround，但必须诚实标注语义限制

### abort 闸验证价值（正面教训）

- 干跑中 option (b) 失效时，abort 闸触发 `[ABORT-CB11] pre_close_net=0 != 0.07`，SELL 未发出 → 验证了闸门能真正拦住「NT net=0 时误发 SELL 变开空」灾难
