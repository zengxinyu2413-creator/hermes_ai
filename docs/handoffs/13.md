## §2 段 A 结论(已完成)

### 2.1 确定性通过的部分
start→RUNNING→disconnect 触发 2 个 task→`asyncio.wait(timeout=10)` 等到 **2 done / 0 still**→stop→STOPPED→**POST-STOP lingering=0**,全程**零发单**,exit_code=0。

teardown 用 `asyncio.wait` 替代了原来的 `sleep(3)`,这是确定性等待 task 完成、而非靠猜。这是段 A 的核心目标,**扎实达成**。

### 2.2 有盲区的部分(本会话查实)
段 A 的 `_ws_snap` 原本读 `is_connected / is_running / is_open` 三个属性来判 WS 是否连上。**这三个属性在 `BinanceUserDataWebSocketClient` 上根本不存在**,五次快照全是 `<no attr>`。

**后果**:"WS keepalive 连接稳定"这条验证目标**实际从未被测量过**。脚本打的 `verdict=CLEAN` 只看 exit_code 和 lingering,没把 `<no attr>` 算进判据 —— 这是 verdict 逻辑的盲区,CLEAN 不能照单全收。

## §3 WS 真属性名(探针实证,本会话核心产出)

探针 `wp5_ws_attr_probe.py` 纯只读(不 start/不 connect/零副作用),对 `exec_client._ws_client` 做 dir()/getattr 内省。结果:

- `_ws_client` 类型 = `BinanceUserDataWebSocketClient`,纯 Python(非 pyo3),56 个属性。
- **PRE-START 状态**(探针未 start,以下全是初始值):
  - `_client = None` —— 底层连接句柄
  - `_stream_client = None` —— user data stream 流句柄
  - `_keepalive_task = None` —— keepalive 协程任务
  - `_reconnect_task = None`
  - `is_authenticated = False`
  - `_base_url = 'wss://ws-api.testnet.binance.vision/ws-api/v3'`(顺带验证 WS 端点确为 testnet ✅)

### 3.1 回填判据(主理人已定排序)
段 A 的 `_ws_snap` 应改读以下属性,**按此权重判**:

| 优先级 | 属性 | 判据 | 说明 |
|---|---|---|---|
| 主 | `_client` | `None → 非 None` = 已连 | WS 物理连接建立的最硬铁证 |
| 主 | `_stream_client` | `None → 非 None` = 流已建 | user data stream 句柄 |
| 辅 | `_keepalive_task` | 非 None = 连接维持中 | keepalive 协程在跑 |
| 辅 | `is_authenticated` | True = 已认证 | **仅表认证,不等于已连接**,降级为辅,勿当主判据 |

> 排序理由:`is_authenticated` 语义是"认证成功"而非"WS 连上",Spot testnet HMAC 下认证与物理连接时序未必同步,当主判据可能误判。主判据用 `_client`。

## §5 本会话失败模式(追加到项目失败档案)

### 5.1 WS 属性名凭假设而非实证
段 A 的 `_ws_snap` 三个属性名是凭空假设的,实类上不存在,导致 WS 验证整条哑掉而 verdict 仍报 CLEAN。**教训**:验证目标用的属性/方法名,必须先用只读探针实证存在,再写进判据;verdict 逻辑要把 `<no attr>` 显式算作 FAIL,不能只看 exit_code。

### 5.2 修复中途发生方向反转,来源非主理人(重点)
loop 参数修复过程中出现一次反方向改动:主理人与复核方共识是 `new_event_loop() → loop=None`(对齐"不创建 event loop"契约),但中途 Claude Code 执行了**相反**的指令(`None → new_event_loop()` 并补 `import asyncio`),把脚本又改回自相矛盾状态。下一轮才纠回 `loop=None`。
**教训**:与上一步共识相反的转向指令,**必须停下来向主理人确认其来源**,不得因"看起来像个指令"就执行。指令来源只认主理人本人。
