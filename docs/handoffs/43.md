  · caller 契约（load/add 签名）不变 → order_id.py 一字未改、无需 carve-out。

- 测试：3 条降级测试（T-deg1 warn 触发 / T-deg2 降级下去重仍正确 / T-deg3 warn 只触发一次）；
  test_seen_store_concurrent.py 三条仍绿（POSIX 路径行为零变化）。
