## §3 .env Ed25519 切换实证档案

### §3.1 Binance Spot Testnet Ed25519 申请流程(供后续参考)

1. 浏览器:`testnet.binance.vision` 登录(独立账号系统,**不是** binance.com 主账号,**不是** demo.binance.com)
2. 点 "Register Public Key"(在 HMAC key 列表下方)
3. 本地终端生成 Ed25519 keypair:
```bash
   mkdir -p /tmp/ed25519_gen && cd /tmp/ed25519_gen
   openssl genpkey -algorithm ed25519 -out ed25519_private.pem
   openssl pkey -in ed25519_private.pem -pubout -out ed25519_public.pem
```
4. 在 console "Register Public Key" 表单:
   - Description: `hermes_ed25519`(或自取,1-20 字符)
   - Permissions: TRADE / USER_DATA / USER_STREAM(照搬 `hermes_test` HMAC key 权限,**不勾** FIX_API/FIX_API_READ_ONLY)
   - Public key: 粘贴 `ed25519_public.pem` 完整内容(3 行 PEM)
5. 提交,Binance console 返回 API Key(对应 .env 里 `BINANCE_TESTNET_API_KEY` 的值)
