## §1 ④ _daily_pnl 跨重启持久 — 实现闭环（commit 1134720 ✅）

### 裁定与设计
现状 `_snapshot()` 故意不存 _daily_pnl，systemd 崩溃重启会归零、白送一次日内回撤熔断额度（生产真实风险）。裁定：修，选项 B（持久 + 日期戳）+ B1（now optional 接缝）。

设计决策 D1-D5：
- D1 日期戳靠调用方喂 now: float，不引 time.* / 不自主取时钟（守 guard.py 零运行时依赖，承 §2.24 CBT1 / LC-RISK-3）。
- D2 跨天判定：snapshot 存 daily_pnl_date（now→UTC date iso）；load 时同日恢复 _daily_pnl，跨日归零。
- D3 向后兼容：旧 snapshot 无 daily_pnl/date 字段 → load 不报错、_daily_pnl=0。
- D4 HALTED 独立：_daily_pnl 持久不影响 HALTED 单向锁 + streak 持久。
- D5 B1 接缝：on_trade_result(pnl, now=None) / reset_daily(now=None)，now=None 维持现状不持久（向后兼容，承 guard.py 三轮 optional-default 范式）。
